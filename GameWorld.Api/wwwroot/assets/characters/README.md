# Bộ minh họa chọn nhân vật

`roster-atlas.png` là bộ minh họa mới được tạo bằng công cụ tạo ảnh trong phiên
phát triển, diễn giải chín tạo hình người dùng cung cấp. Đây không phải các ảnh
gốc đã tải lên và không phải mô hình 3D. Không dùng artwork lấy từ website ngoài.

Atlas có 3 cột × 3 hàng; thứ tự trùng `character-catalog.js`:

1. Thiên Cơ — lá bài tinh tú.
2. Băng Long — tóc bạc, rồng băng.
3. Xích Hồ — tai cáo, khăn đỏ, đao lửa.
4. Lam Lang — tóc xanh, sói, cung tên.
5. Hải Phong — khăn đỏ, áo mở, đao cong.
6. Long Vệ — giáp rồng bạc.
7. Nguyệt Kiếm — tóc buộc cao, song kiếm.
8. Kim Hầu — chiến binh khỉ, trường côn.
9. Huyền Ảnh — nón rộng vành, chim sẻ, hỏa khí.

Tên và cốt truyện là đề xuất thiết kế. Để bổ sung nhân vật sau này, cập nhật dữ
liệu catalog và artwork/CSS tương ứng; không thay ID cũ nếu muốn giữ yêu thích.
